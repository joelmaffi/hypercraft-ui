# 01. Anti-Slop Craft Floor & Quality Standards

The "Craft Floor" defines the non-negotiable minimum quality standard for any UI produced by an AI coding agent. It is designed to eradicate the repetitive patterns, lazy defaults, and visual tells that immediately signal an interface was generated by an unguided AI model.

---

## The Anatomy of "AI Slop"

Current AI models default to a predictable cluster of aesthetics:
1. **The Warm Cream / Terracotta Broadsheet**: A cream background (`#F4F1EA`), serif display typeface, hairline dividers everywhere, and a warm terracotta or burnt clay button (`#D97757`).
2. **The Dark Void / Acid Neon Gamer**: A near-black `#0A0A0A` background, pure white text, and a single piercing lime-green or neon-cyan accent (`#22C55E` or `#06B6D4`).
3. **The 3-Card SaaS Monoculture**: A headline centered on the screen, followed by three identical rounded cards with a colored icon box, an `h3` heading, and two lines of gray muted text.
4. **The Eyebrow Crutch**: Putting a tiny uppercase pill or tracking-heavy subtitle above every heading (e.g. `// ANALYTICS PLATFORM`, `POWERFUL CAPABILITIES`).
5. **Decoration Masquerading as Depth**: Random glassmorphism (`backdrop-blur-md bg-white/5 border-white/10`) on static cards where nothing is blurred underneath, or hard zero-blur offset block shadows (`box-shadow: 4px 4px 0 #000`).

When an interface relies on these defaults, it signals to users that no human considered their specific problem, industry, or needs.

---

## The 10 Bans: Detailed Rules & Code Fixes

### 1. BAN: Kicker / Eyebrow Above Headings
- **The Slop**:
  ```html
  <!-- BAD: Timid AI label -->
  <span class="text-xs uppercase tracking-wider text-indigo-500 font-semibold mb-2 block">
    // REAL-TIME OBSERVABILITY
  </span>
  <h2 class="text-3xl font-bold text-gray-900">Zero-overhead telemetry for distributed systems</h2>
  ```
- **The World-Class Fix**: Delete the label entirely. Make the headline confident, specific, and self-contained:
  ```html
  <!-- GOOD: Confident, authoritative headline -->
  <h2 class="text-3xl font-semibold tracking-tight text-neutral-900 dark:text-neutral-50 max-w-2xl">
    Zero-overhead telemetry for distributed systems
  </h2>
  ```

---

### 2. BAN: Generic Same-Size 3-Card Grids
- **The Slop**: Three identical boxes side-by-side with an icon, title, and sentence.
- **The World-Class Fix**: Asymmetric Bento composition, interactive feature walkthroughs, or real UI snapshots:
  ```tsx
  // GOOD: Asymmetric Bento Grid reflecting actual feature hierarchy
  <div class="grid grid-cols-1 md:grid-cols-12 gap-6">
    {/* Primary Hero Feature (8 cols) */}
    <div class="md:col-span-8 bg-neutral-900 text-white rounded-2xl p-8 border border-neutral-800 relative overflow-hidden">
      <div class="max-w-md">
        <h3 class="text-2xl font-medium tracking-tight">Interactive Query Engine</h3>
        <p class="text-neutral-400 mt-2 text-sm leading-relaxed">
          Execute sub-millisecond vector lookups over 100M+ embeddings with automatic partition pruning.
        </p>
      </div>
      {/* Live Interactive Widget or Terminal Preview */}
      <div class="mt-6 rounded-xl bg-neutral-950 p-4 border border-neutral-800/80 font-mono text-xs">
        <span class="text-emerald-400">$</span> query --latency --top-k=5
      </div>
    </div>

    {/* Secondary Stat Feature (4 cols) */}
    <div class="md:col-span-4 bg-white dark:bg-neutral-900 rounded-2xl p-8 border border-neutral-200 dark:border-neutral-800 flex flex-col justify-between">
      <div>
        <h3 class="text-lg font-medium tracking-tight">P99 Latency</h3>
        <p class="text-neutral-500 text-sm mt-1">Sustained across all clusters.</p>
      </div>
      <div class="mt-8">
        <div class="text-5xl font-semibold tracking-tight font-mono text-neutral-900 dark:text-neutral-50">
          1.8<span class="text-2xl text-neutral-400 font-normal">ms</span>
        </div>
        <div class="text-xs text-emerald-600 dark:text-emerald-400 mt-2 font-medium flex items-center gap-1">
          <ArrowDownRight className="w-4 h-4" /> 42% faster than v2.4
        </div>
      </div>
    </div>
  </div>
  ```

---

### 3. BAN: Cliché AI Color Schemes
- **The Slop**: Warm cream + terracotta or pure dark void + toxic green.
- **The World-Class Fix**: Root your palette in the physical materials and environment of your domain:
  - *Engineering / Aerospace*: Deep slate blue canvas, zinc surfaces, international safety orange or cobalt blue action accents.
  - *Fintech / Institutional Asset Management*: Deep forest emerald, crisp off-white paper, brass/bronze warm metadata highlights.
  - *Creative / Media Studio*: Neutral monochrome foundation (pure zinc or slate) allowing user content and rich media to own the color space.

---

### 4. BAN: Arbitrary Gradient Text
- **The Slop**:
  ```html
  <!-- BAD: Cheesy rainbow or purple-pink gradient -->
  <h1 class="text-5xl font-extrabold bg-gradient-to-r from-purple-600 via-pink-600 to-blue-600 bg-clip-text text-transparent">
    Supercharge your workflow with AI
  </h1>
  ```
- **The World-Class Fix**: High-contrast, beautifully kerned solid typography with purposeful weight contrast:
  ```html
  <!-- GOOD: Clean, commanding, timeless typography -->
  <h1 class="text-5xl font-semibold tracking-tight text-neutral-900 dark:text-neutral-50 leading-[1.08]">
    Supercharge your workflow. <span class="text-neutral-400 font-normal">Built for engineers who care about craft.</span>
  </h1>
  ```

---

### 5. BAN: Unmotivated Glassmorphism
- **The Slop**: Applying `backdrop-blur` to static cards resting on a solid background. (Blurring a solid color produces zero visual effect while burning GPU compositor cycles).
- **The World-Class Fix**: Use backdrop blur ONLY where content dynamically scrolls underneath:
  ```html
  <!-- GOOD: Sticky floating header with contextual blur -->
  <header class="sticky top-0 z-50 w-full border-b border-neutral-200/60 dark:border-neutral-800/60 bg-white/80 dark:bg-neutral-950/80 backdrop-blur-md supports-[backdrop-filter]:bg-white/60">
    <!-- Header contents -->
  </header>
  ```

---

### 6. BAN: Hard Zero-Blur Block Shadows
- **The Slop**: `box-shadow: 4px 4px 0px #000` on a modern clean SaaS interface.
- **The World-Class Fix**: Layered, realistic physics-based ambient shadows:
  ```css
  /* GOOD: Multi-layered ambient shadow system */
  .elevation-sm {
    box-shadow: 0 1px 2px 0 rgb(0 0 0 / 0.05);
  }
  .elevation-md {
    box-shadow: 
      0 4px 6px -1px rgb(0 0 0 / 0.06),
      0 2px 4px -2px rgb(0 0 0 / 0.04),
      0 0 0 1px rgb(0 0 0 / 0.03); /* Subtle keyline border */
  }
  .elevation-lg {
    box-shadow: 
      0 10px 15px -3px rgb(0 0 0 / 0.07),
      0 4px 6px -4px rgb(0 0 0 / 0.05),
      0 0 0 1px rgb(0 0 0 / 0.04);
  }
  ```

---

### 7. BAN: Numbered Markers (01 / 02 / 03) on Non-Sequences
- **The Slop**: Numbering three arbitrary benefits (e.g. `01 Speed`, `02 Security`, `03 Scalability`). Speed does not happen before Security.
- **The World-Class Fix**: Reserve numbers strictly for chronological onboarding flows, step wizards, or sorted rank orders.

---

### 8. BAN: Stock Emoji or Unicode Glyphs
- **The Slop**: `<button>🚀 Launch App</button>` or `<div class="card">🔥 Hot Features</div>`.
- **The World-Class Fix**: Cohesive, vector-stroked icons with optical alignment:
  ```tsx
  import { Rocket, Sparkles, CheckCircle2 } from "lucide-react"

  <button className="inline-flex items-center gap-2 px-4 py-2 bg-neutral-900 text-white rounded-lg text-sm font-medium hover:bg-neutral-800 transition-colors">
    <Rocket className="w-4 h-4 text-neutral-300" strokeWidth={1.75} />
    <span>Deploy Cluster</span>
  </button>
  ```

---

### 9. BAN: Dummy Placeholder Data
- **The Slop**: "John Doe bought Item A for $100.00".
- **The World-Class Fix**: Realistic domain context:
  - *DevTools*: `commit 8f3a9e1 by alex.v on main: fix(query-planner): prevent partition scan on index hit`
  - *Fintech*: `ACH Transfer · Stripe Inc. · Reference #TXN-90218-E · Settled at 14:32 UTC`
  - *Healthcare*: `Patient ID #HC-40291 · SpO2: 98% · Pulse: 72 bpm · Sinus Rhythm`

---

### 10. BAN: Un-Themed Browser Surfaces
Every browser ships with unstyled defaults that ruin custom interfaces. Always override them:

```css
/* 1. Themed Text Selection */
::selection {
  background-color: var(--color-primary-subtle, oklch(90% 0.08 260));
  color: var(--color-primary-strong, oklch(30% 0.2 260));
}

/* 2. Custom Sleek Scrollbars */
::-webkit-scrollbar {
  width: 8px;
  height: 8px;
}
::-webkit-scrollbar-track {
  background: transparent;
}
::-webkit-scrollbar-thumb {
  background: oklch(70% 0.02 240 / 0.4);
  border-radius: 9999px;
  border: 2px solid transparent;
  background-clip: content-box;
}
::-webkit-scrollbar-thumb:hover {
  background: oklch(50% 0.03 240 / 0.6);
}

/* 3. Accessible, Beautiful Focus Rings */
:focus-visible {
  outline: none;
  box-shadow: 
    0 0 0 2px var(--bg-canvas, #ffffff),
    0 0 0 4px var(--action-primary, #6366f1);
}

/* 4. Tabular Numerals for Alignment */
.tabular-numbers, [data-numeric] {
  font-variant-numeric: tabular-nums lining-nums;
  letter-spacing: -0.01em;
}
```

## The Squint Test (Optical Hierarchy)

When evaluating any UI layout:
1. Blur your eyes or zoom out to 25%.
2. Identify the **Primary Visual Anchor** (the single element that captures attention first).
3. Identify the **Secondary Path** (where the eye travels next).
4. Identify the **Tertiary Elements** (supporting metadata, controls, breadcrumbs).

If all elements appear with identical visual contrast or spacing, the layout fails. Introduce **scale contrast**, **weight contrast**, or **whitespace generosity** to establish effortless hierarchy.
